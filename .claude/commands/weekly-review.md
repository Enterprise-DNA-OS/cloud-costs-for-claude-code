# Weekly review

Run `npm run costs -- showback --json`, `npm run costs -- budget-review --json`, `npm run costs -- cost-changes --json`, `npm run costs -- attention --json` and `npm run costs -- allocation-check --json`. Summarise costs by currency, budget exceptions, incomplete periods and overdue investigations. Link each recommendation to evidence. Ask for an owner and date before recording new actions. Never claim that a spend decrease proves savings.
