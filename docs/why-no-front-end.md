# Why the review desk has no application front end

A weekly cost review needs clear totals, owners, allocation reasons and follow-up evidence. Those are records and repeatable queries. The CLI reads and updates them; a coding agent translates an operator's request into that CLI. Read-only HTML statements and dashboards show the result.

A screen gives convenient filters, visual chart exploration, team navigation, mobile access and guided forms. This free version does not provide those interactions, live collaboration, offline mobile sync or a provider collector. Enterprise DNA can build a web view and the required connections into your version.

Generated HTML is a point-in-time document, not a live dashboard. Re-render after importing or changing records. No hosted application, daemon, cloud account access or automated infrastructure action is required.
